title: Traffic Capture

---

The **Traffic Capture Panel** lets you sniff and analyze communication between readers and cards.

## Supported Protocols

| Protocol   | Description                   |
| ---------- | ----------------------------- |
| ISO14443-A | Mifare Classic, DESFire, NTAG |
| ISO14443-B | Calypso, SRI512               |
| ISO15693   | iCLASS, ICODE                 |
| LF         | Low-frequency protocols       |
| iCLASS     | HID iCLASS specific commands  |

## Features

- **Raw frame capture** — see every byte exchanged
- **Protocol decoding** — automatic frame interpretation
- **CRC validation** — visual indicators for valid/invalid CRCs
- **Direction tracking** — distinguish reader commands from tag responses
- **Frame annotation** — decoded command names and parameters
- **Filtering** — filter by protocol, direction, or content
