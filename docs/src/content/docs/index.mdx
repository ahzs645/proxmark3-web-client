## Features

<CardGrid stagger>
  <Card title="HF Attacks" icon="rocket">
    Autopwn, Nested, Darkside, Hardnested, and Static Nested — all from a clean UI.
  </Card>
  <Card title="Magic Cards" icon="pencil">
    Full Gen1a, Gen2, Gen3, and Gen4 (GTU) magic card support with UID manipulation.
  </Card>
  <Card title="LF Operations" icon="setting">
    EM410x read/write, T55xx block access, and configurable LF sampling.
  </Card>
  <Card title="Runs in Your Browser" icon="laptop">
    Proxmark3 firmware compiled to WASM — everything runs client-side via Web Serial.
  </Card>
</CardGrid>
